# ארכיון בחינות מכניקה 20215

בדיקה
אתר סטטי, בלי שלב בנייה:

- `index.html` – הדף עצמו.
- `exams.js` – כל התוכן: בחינות, שאלות ופתרונות.
- `figs/` – האיורים שנחתכו מהבחינות.
- `pdfs/` – קובצי הבחינות המקוריים.

## העלאה ל-GitHub Pages
1. ב-GitHub: New repository. תנו שם, למשל `mechanics-exams`, ובחרו Public.
2. בדף המאגר: Add file → Upload files. גררו את **תוכן** התיקייה (index.html, exams.js, README.md ואת התיקיות figs ו-pdfs), ולחצו Commit.
3. Settings → Pages → Source: `Deploy from a branch`, ענף `main`, תיקייה `/ (root)` → Save.
4. אחרי כדקה האתר יופיע בכתובת `https://<שם-המשתמש>.github.io/<שם-המאגר>/`.

## הוספת בחינה
1. שמרו את ה-PDF ב-`pdfs/` ואת האיורים ב-`figs/`.
2. בסוף `exams.js`, לפני שורות ה-`forEach` וה-`sort`, הוסיפו בלוק `window.EXAMS.push({...});`. אפשר להעתיק בלוק קיים ולעדכן אותו.
3. שדות הבחינה:
   - `id`: מזהה ייחודי.
   - `iso`: תאריך בפורמט YYYY-MM-DD, למיון.
   - `semester`, `moed`, `date`, `heDate`: פרטי הבחינה.
   - `pdf`: נתיב לקובץ הבחינה.
4. בכל שאלה, השדה `fig` יכול להיות נתיב לאיור אחד, רשימת נתיבים (`["figs/a.png","figs/b.png"]`) או `null`.
5. נוסחאות כותבים ב-LaTeX: `\( ... \)` בתוך שורה, `\[ ... \]` בשורה נפרדת. כל טקסט עטוף ב-``String.raw`...` `` כדי שהלוכסנים יישמרו.
6. השדה `tags` קובע את כפתורי הנושאים בראש העמוד.

## בדיקה מקומית
כשפותחים את `index.html` ישירות (בלחיצה כפולה), האתר עובד. הנוסחאות מעוצבות רק כשיש חיבור לאינטרנט, כי MathJax נטען מ-CDN.

## עריכת שאלות ופתרונות
1. פתחו את האתר ולחצו על "✎ מצב עריכה" בראש העמוד. ליד כל שאלה יופיע כפתור "ערוך שאלה".
2. אפשר לשנות כותרת, נושאים, נוסח, סעיפים (כולל ניקוד, הוספה ומחיקה) ופתרון. התצוגה המקדימה מתעדכנת תוך כדי הקלדה.
3. אחרי "שמור" השינוי נשמר בדפדפן. כדי שיגיע לאתר: "הורד exams.js מעודכן" והחלפת `exams.js` בתיקייה (בגרסה שמתארחת ב-Claude הקובץ יורד בשם `exams.txt`, וצריך לשנות את שמו ל-`exams.js`).
4. "החזר לנוסח המקורי" מבטל את העריכה של שאלה אחת. "בטל את כל השינויים" מבטל הכול.

## עריכת ההסברים הקוליים
1. פתחו את האתר ולחצו על "✎ עריכת הסברים" בראש העמוד. ליד כל שאלה יופיע כפתור "ערוך" או "כתוב הסבר".
2. כתבו או תקנו את הטקסט. פסקאות מפרידים בשורה ריקה. אפשר להשמיע את הטיוטה לפני השמירה.
3. השינויים נשמרים בדפדפן שלכם. כדי שיגיעו לאתר עצמו, לחצו "הורד audio.js מעודכן" והחליפו בקובץ שהורד את `audio.js` שבתיקייה. בגרסה שמתארחת ב-Claude הקובץ יורד בשם `audio.txt`, וצריך לשנות את שמו ל-`audio.js`.

## קול טבעי (ElevenLabs)
אפשר להפיק לכל הסבר קובץ MP3 בקול טבעי. כשיש קובץ כזה, האתר מנגן אותו במקום ההקראה של הדפדפן.
1. ב-ElevenLabs: Voices ← בחרו קול עברי ← "Copy voice ID". את מפתח ה-API מוצאים תחת Developers ← API Keys.
2. לחיצה כפולה על `tools\generate-audio.bat`. בהרצה הראשונה הסקריפט מבקש את מזהה הקול ושומר אותו ב-`tools\elevenlabs-settings.json`.
3. הסקריפט מציג כמה תווים יידרשו ומבקש אישור (y). אחר כך הוא מבקש את מפתח ה-API, והקלדת המפתח מוסתרת. המפתח לא נשמר בשום מקום.
4. הקבצים נשמרים בתיקייה `audio\`, והרשימה שלהם ב-`audio-files.js`. מעלים את שניהם ל-GitHub יחד עם שאר האתר.
- בהרצה חוזרת נוצרים מחדש רק הסברים שהטקסט שלהם השתנה, או אם הוחלף הקול. אם הסבר נערך ועדיין לא הוקלט מחדש, האתר חוזר להקראה של הדפדפן.
- כדי להפיק רק שאלה מסוימת: `generate-audio.bat 2024b-94-3`.
- כדי להחליף קול או מודל, עורכים את `tools\elevenlabs-settings.json`. ברירת המחדל היא `eleven_v3`, שתומך בעברית.
